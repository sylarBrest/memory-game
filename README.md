# Memory Game

A great old classic game that is still fun.

## Features

- IT brands themed card images

- The best scores make it to the Top 10 leaderboard.

- You can always see your current move count and the number of pairs found.

- You can start a new game at any time.

  **_Warning!_** Your current progress will be lost.

## How to play

1. You can [play online](https://sylarbrest.github.io/memory-game/ 'Play online Memory game') or...

2. You can [download archive](https://github.com/sylarBrest/memory-game/archive/refs/heads/memory-game.zip 'Download from GitHub') with the game and unzip to your folder.

3. Go to the folder and open **index.html** with your favorite browser.

## Rules

1. Every time you start a new game, you get a completely randomized board.

2. Flip over any two cards on your turn.

3. If the cards match, they stay face up.

4. If they don't match, they flip back over after one second.

### Enjoy!
